## 4. План реализации `main.py` (по пунктам ТЗ, по порядку) — реализовано

- [x] **Импорты**: `argparse`, `asyncio`, `logging`, `shutil`, `Path` из `pathlib` (без сторонних пакетов — см. п.2)
- [x] **ArgumentParser**: `parse_args()` с описанием скрипта
- [x] **Аргументы командной строки**: `-s`/`--source` (обязательный) и `-o`/`--output` (по умолчанию `'dist'`)
- [x] **Логирование**: `logging.basicConfig(...)`, уровень `INFO`, ошибки копирования — через `logger.error(...)`
- [x] **Асинхронные пути**: не через `AsyncPath` (см. п.2), а через `asyncio.to_thread(...)`, оборачивающий блокирующие вызовы `pathlib`/`shutil` — тот же эффект (не блокировать Event loop), другой инструмент
- [x] **`copy_file(file_path, output_folder)`** — асинхронная функция:
  - определяет расширение файла (`file_path.suffix`, без точки; если расширения нет — папка `no_extension`)
  - создаёт подпапку `output_folder/<ext>` через `await asyncio.to_thread(target_dir.mkdir, exist_ok=True, parents=True)`
  - копирует файл через `await asyncio.to_thread(shutil.copyfile, file_path, target_dir / file_path.name)`
  - оборачивает всё в `try/except`, ошибки — в `logger.error(...)`, не прерывая всю программу
- [x] **`read_folder(source_folder, output_folder)`** — асинхронная рекурсивная функция:
  - получает список содержимого папки через `await asyncio.to_thread(list, source_folder.iterdir())`
  - если элемент — папка: рекурсивно вызывает себя же на этой подпапке
  - если файл: создаёт задачу `asyncio.create_task(copy_file(item, output_folder))`
  - все задачи текущего уровня собираются и ожидаются через `await asyncio.gather(*tasks)` — копируются параллельно
- [x] **Главный блок**: `async def main()` — парсит аргументы, проверяет существование `source`, создаёт `output`, вызывает `read_folder`; запуск через `asyncio.run(main())` в `if __name__ == '__main__':`

**Известный нюанс (пока не решено):** структура "плоская" — все файлы с одним расширением из разных подпапок источника попадают в одну и ту же папку назначения. При совпадении имён файлов из разных подпапок один молча перезапишет другой (`shutil.copyfile` не предупреждает о перезаписи). Поймали это на тестовой папке (`text1.txt` в двух местах).
